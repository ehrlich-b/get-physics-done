# Phase 64.1 — Blast-radius audit: CODE consumers of the det_3 cross-term bug

**Probe:** the bug bites only on GENUINELY OCTONIONIC h_3(O) elements (nonzero
e_1..e_6 octonion components in off-diagonals) used as the F_4-invariant cubic
norm / determinant / eigenvalue spectrum. It is INVISIBLE on diagonal / real /
complex-slice elements, under the Spin(9) realization, under g_2, and under
diagonal permutations. A PSD yes/no verdict can be robust even when the
eigenvalues are wrong.

## Assessment

- **v16.0 (this milestone):** fixed. Clean going forward.
- **v15.0 engine (`embedding_under_E_verification.py`):** `T3`/`reduced_charpoly_roots`
  carry the bug, so octonionic EIGENVALUES are wrong. But the two v15.0 decisive
  uses are robust-in-effect: the PSD verdict on the actual ambient element did NOT
  flip (verified), and the ambient sqrt is self-validated by exact squaring.
  Whether the v15.0 PAPER reports/depends on specific octonionic eigenvalues or
  norm values is the open question (paper audit running).
- **`octonion_algebra.py`:** the bug's origin; `det_3`/`polarize_d`/`sharp` are
  suspect on octonionic data, and `verify_f4_invariance_det3` is an inadequate
  test (Spin(9) realization masks the bug). Consumers in Paper 7 / prior phases
  need the paper-level triage.

## Recommended remediation (for Bryan's decision — NOT done unilaterally)

1. **`embedding_under_E_verification.py` T3 cross-term:** recommend the same
   one-line fix (`(x1 x2) x3` -> `(x2 x1) x3`) + re-run its harness, to stop the
   bug being a latent landmine and to prevent future ports re-importing it. It is
   archived v15.0 code, so this is Bryan's call.
2. **`octonion_algebra.py` det_3 (2152) + sharp + `verify_f4_invariance_det3`:**
   recommend fixing the cross term AND upgrading `verify_f4_invariance_det3` to
   test inner-derivation ([L_a,L_b]) annihilation (not just Spin(9)/g_2/perm).
   Wide blast radius — sequence behind the paper triage.
3. Do NOT assume any octonionic det/norm/eigenvalue VALUE printed in prior outputs
   is correct without re-checking against the corrected norm.
