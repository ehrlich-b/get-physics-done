  <action>
    Add to code/octonion_algebra.py:

    1. **det_3(X):** Takes an H3O object, returns the cubic norm:
       N(X) = X.alpha * X.beta * X.gamma - X.alpha * X.x1.norm_sq() - X.beta * X.x2.norm_sq() - X.gamma * X.x3.norm_sq() + 2 * ((X.x1 * X.x2) * X.x3).c[0]

       CRITICAL: The cross-term is Re((x1*x2)*x3). Compute x1*x2 FIRST (an Octonion), THEN multiply by x3, THEN take .c[0] for the real part. This is left-to-right association matching the H3O matrix layout Sarrus expansion.

       Do NOT use x1*(x2*x3) -- this gives a different value due to octonion non-associativity.

    2. **polarize_d(X, Y, Z):** Takes three H3O objects, returns the symmetric trilinear form:
       d(X,Y,Z) = det_3(X+Y+Z) - det_3(X+Y) - det_3(X+Z) - det_3(Y+Z) + det_3(X) + det_3(Y) + det_3(Z)

       This requires H3O addition. If H3O does not support __add__, implement it: add component-wise (alpha+alpha, beta+beta, gamma+gamma, x1+x1, x2+x2, x3+x3). Also implement scalar multiplication __rmul__ if not present: scale all components by the scalar.

    3. **peirce_basis_27():** Returns a list of 27 H3O objects forming the Peirce-adapted basis:
       - Index 0: E_{11} = H3O(alpha=1, beta=0, gamma=0, x1=0, x2=0, x3=0)  [V_1]
       - Indices 1-16: from Vhalf_basis_vectors(), converted to H3O  [V_{1/2}]
       - Indices 17-26: from V0_basis_elements()  [V_0]

       V_{1/2} basis vectors are pairs (a,b) in O^2 embedded as H3O with alpha=0, x2=a (note: x2 maps to position (1,3)), x3=b (position (2,1)), beta=gamma=x1=0 per the Peirce V_{1/2} embedding. Consult the existing Vhalf_basis_vectors() and L_E11 to confirm the correct embedding.

    4. **Verify det_3:**
       - det_3(I_3) = 1 where I_3 = H3O(1,1,1, Octonion.zero(), Octonion.zero(), Octonion.zero())
       - det_3(E_{11}) = 0, det_3(E_{22}) = 0, det_3(E_{33}) = 0
       - det_3(diag(a,b,c)) = abc for 5 random (a,b,c) triples
       - Cubic homogeneity: det_3(lambda*X) = lambda^3 * det_3(X) for 10 random X, 5 lambda values
       - h_3(C_u) restriction: for X with x1, x2, x3 in C_u = span{1, e_7}, det_3 matches standard complex 3x3 det

    5. **Verify polarization:**
       - Symmetry: d(X,Y,Z) = d(Y,X,Z) = d(X,Z,Y) = ... for 20 random triples
       - Polarization identity: d(X,X,X) = 6*N(X) for 20 random X (with our inclusion-exclusion convention)
