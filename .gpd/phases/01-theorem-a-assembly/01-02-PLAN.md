  <files>derivations/theorem-a-proof.tex</files>
  <action>
    Using the 7 lemma statements from Plan 01 (derivations/theorem-a-lemmas.tex), compose the error terms through the dependency graph to produce the complete Theorem A proof.

    **Step 1: Identify all error correction factors.**
    From each lemma, extract the correction factor:
    - L1: exact (no correction)
    - L2: delta_2 = O(exp(-c_2/epsilon))
    - L3: delta_3 = C_3 * exp(-gamma_D * t) for the QSD convergence
    - L4: delta_4 = 1/(gamma_D * tau_exit) = O(exp(-Delta_s/epsilon)) (superexponentially small)
    - L5: delta_5 = O(exp(-c_5/epsilon))
    - L6: concentration bound (either DV or BEGK exponential law)
    - L7: algebraic combination (no independent error term, just propagates)

    **Step 2: Trace the composition chain.**
    Following the typed dependency graph from Plan 01:

    L1 -> L2: Basin partition feeds into residence time. No error propagation (L1 is exact).
    L1 -> L3: Basin partition feeds into QSD construction. No error propagation.
    L2 + L3 -> L4:
      mu_stable >= c * K_s * exp(Delta_s/epsilon) * (1 - delta_4)
      where (1 - delta_4) accounts for the QSD transient.
      Error: delta_4 = O(exp(-Delta_s/epsilon)) which is LESS than the main term's exponent, so negligible.

    L2 -> L5 (via renewal):
      mu_BB <= rho_max * K_b * exp((Delta_b - alpha)/epsilon) * (1 + delta_5)
      Error: delta_5 comes from the renewal approximation.

    L6 converts expectations to high-probability bounds:
      If using BEGK Thm 1.4: tau_exit/E[tau_exit] -> Exp(1), giving concentration of residence time.
      If using DV: empirical measure concentrates with rate function I > 0 since T is exponentially large.
      The concentration converts E[mu_stable] and E[mu_BB] to high-probability statements with exponentially small failure probability.

    L4 + L5 + L6 -> L7:
      mu_BB/mu_stable <= [(rho_max * K_b * exp((Delta_b-alpha)/epsilon) * (1+delta_5)] / [c * K_s * exp(Delta_s/epsilon) * (1-delta_4)]
      = (rho_max * K_b)/(c * K_s) * exp(-(Delta_s - Delta_b - alpha)/epsilon) * (1+delta_5)/(1-delta_4)

    **Step 3: Verify the correction product.**
    (1+delta_5)/(1-delta_4) = (1+delta_5)(1+delta_4+delta_4^2+...) = 1 + delta_4 + delta_5 + O(delta_4*delta_5)
    Since delta_4 = O(exp(-Delta_s/epsilon)) and delta_5 = O(exp(-c_5/epsilon)), the product correction is:
      O(exp(-min(Delta_s, c_5)/epsilon))
    This is exponentially small provided min(Delta_s, c_5) > 0, which holds by assumption.

    Key check: min(Delta_s, c_5) vs (Delta_s - Delta_b - alpha). If min(Delta_s, c_5) > Delta_s - Delta_b - alpha, the correction is negligible compared to the main exponential suppression. If not, the correction modifies the effective exponent.

    In fact, since Delta_s > Delta_s - Delta_b - alpha (because Delta_b + alpha > 0), the delta_4 correction is always sub-leading. For delta_5, we need c_5 > 0 at minimum. If c_5 > Delta_s - Delta_b - alpha, then delta_5 is sub-leading too.

    **Step 4: Write the complete proof.**
    State Theorem A. Then:
    "Proof. By Lemma 1 (FW, Thm 6.3.1), decompose ... By Lemma 2 (BEGK, Thm 1.2), the mean exit time ... [continue through all 7 lemmas]. The error corrections compose as follows: [explicit computation from Step 3]. Therefore mu_BB/mu_stable <= C * exp(-(Delta_s - Delta_b - alpha)/epsilon) where C = (rho_max * K_b)/(c * K_s). QED."

    **Step 5: Write the explicit formula for C.**
    Express C in terms of the problem parameters:
    - rho_max = H(B)/4 (maximum of rho on the simplex)
    - c = rho(nu_QSD) (experiential density at the QSD in B_stable)
    - K_s, K_b = BEGK prefactors from the capacity formula
    For the three-state chain: K_s/K_b = 1 (by symmetry of the linear chain structure), so C = (rho_max/c) * (1-p)/p = (rho_b/rho_s) * (1-p)/p.

    **Step 6: State the constraint on alpha.**
    0 < alpha < Delta_s - Delta_b is required for the bound to give exponential suppression. At alpha = 0, the observation time equals the mean exit time and P(exit before T) is O(1). At alpha = Delta_s - Delta_b, the exponent vanishes and there is no suppression.

    Write the proof as a self-contained document. Constants may be deferred to an appendix (per approved decision), but the main argument must have no gaps.
