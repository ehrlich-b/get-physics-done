  <name>Task 1: State the 7 lemmas with explicit error terms and literature citations</name>
  <files>derivations/theorem-a-lemmas.tex</files>
  <action>
    For each of the 7 lemmas, write a precise mathematical statement with:
    (a) The exact mathematical claim
    (b) The specific theorem from the source literature that supplies it
    (c) The error term in the form "exact_quantity * (1 + delta_i)" where delta_i = O(exp(-c_i/epsilon)) and c_i is identified
    (d) The conditions under which the lemma holds

    The 7 lemmas, in dependency order:

    **Lemma 1 (Basin Partition):** Apply FW cycle hierarchy (Freidlin-Wentzell Ch.6, Thm 6.3.1) to decompose the state space into metastable sets B_stable and B_BB with communication heights Delta_s and Delta_b. This is a graph-theoretic construction -- no error term needed (exact decomposition). Output: the basin partition and communication heights.

    **Lemma 2 (Residence Time Lower Bound):** Apply BEGK capacity formula (Bovier et al., Comm. Math. Phys. 228, Thm 1.2). For a reversible chain with generator Q_eps on finite state space, the mean exit time from B_stable satisfies:
      E_x[tau_{B_stable^c}] = (1/(pi(x) * cap(x, B_stable^c))) * (1 + delta_2)
    where delta_2 = O(exp(-c_2/epsilon)) with c_2 related to the sub-leading communication height. The key result is E[tau] ~ K * exp(Delta_s/epsilon). Cite Bovier-den Hollander Ch.7, Thm 7.8 for the capacity formula and the sharp error estimate.

    Also cite BEGK Thm 1.4 for the exponential law: tau_{exit} / E[tau_{exit}] converges in distribution to Exponential(1). This gives concentration of the exit time around its mean without needing DV (relevant to Lemma 6 discussion).

    **Lemma 3 (QSD Convergence):** The killed chain (chain restricted to B_stable with absorption at boundary) has a unique QSD nu_QSD. The conditional distribution converges:
      ||p_t^{killed} - nu_QSD||_TV <= C_3 * exp(-gamma_D * t)
    where gamma_D is the spectral gap of the killed generator. Cite Champagnat-Villemonais, PTRF 164 (2016), main theorem. Note: gamma_D must be polynomial in chain parameters (not exponentially small) -- this holds because the killed chain's spectral gap is bounded below by a function of the basin size and minimum transition rate within the basin, which are O(1) as epsilon -> 0 (the exponentially small rates are the inter-basin rates, which are removed by the killing). State this explicitly.

    **Lemma 4 (Stable Measure Lower Bound):** Combine Lemmas 2 and 3. During residence time ~exp(Delta_s/epsilon) in B_stable, the chain is at QSD for all but a transient period of O(1/gamma_D). The experiential density rho(nu_QSD) >= c > 0 by assumption (density bounds from Theorem A setup). Therefore:
      mu_stable >= c * (1 - delta_4) * exp(Delta_s/epsilon) * K_s
    where delta_4 = O(exp(-gamma_D * t_transient)) accounts for the initial transient before QSD convergence, and K_s is the residence time prefactor. Since gamma_D = O(1) and t_transient = O(1) while residence time is exp(Delta_s/epsilon), we have delta_4 = O(1/exp(Delta_s/epsilon)) which is superexponentially small.

    Actually, more carefully: mu_stable = integral_0^{tau_exit} rho(p_t) dt. During the first ~1/gamma_D time, p_t differs from QSD. After that, rho(p_t) ~ rho(nu_QSD) >= c. So:
      mu_stable >= c * (tau_exit - 1/gamma_D) >= c * tau_exit * (1 - 1/(gamma_D * tau_exit))
    Since tau_exit ~ exp(Delta_s/epsilon) and gamma_D = O(1), the correction 1/(gamma_D * tau_exit) is O(exp(-Delta_s/epsilon)).

    **Lemma 5 (BB Occupation Upper Bound):** By renewal theory: the chain makes N excursions to B_BB before observation time T_eps expires, where N ~ T_eps / E[tau_{cycle}] and each cycle takes ~exp(Delta_s/epsilon) time. Each BB excursion lasts ~exp(Delta_b/epsilon). Total BB occupation:
      tau_BB(T_eps) <= N * K_b * exp(Delta_b/epsilon) * (1 + delta_5)
    where N ~ exp((Delta_s - alpha)/epsilon) / exp(Delta_s/epsilon) = exp(-alpha/epsilon), so N is exponentially small. Wait -- this means the chain makes fewer than 1 excursion on average during T_eps. More precisely: P(any BB excursion before T_eps) ~ T_eps / E[tau_{exit}] = exp(-alpha/epsilon), so with probability 1 - exp(-alpha/epsilon) there are zero BB excursions.

    Conditional on one excursion occurring, the BB occupation time is ~exp(Delta_b/epsilon). So:
      E[tau_BB(T_eps)] <= exp(-alpha/epsilon) * exp(Delta_b/epsilon) * K_b * (1 + delta_5)
    Therefore:
      mu_BB <= rho_max * E[tau_BB] <= rho_max * K_b * exp((Delta_b - alpha)/epsilon) * (1 + delta_5)
    where rho_max = H(B)/4 and delta_5 = O(exp(-c_5/epsilon)).

    **Lemma 6 (DV Concentration):** The time-averaged experiential measure concentrates around its expected value. For a functional of an ergodic Markov chain, the DV rate function gives:
      P(|mu/T - E[mu/T]| > eta) <= exp(-T * I(eta))
    Since T = T_eps = exp((Delta_s-alpha)/epsilon) is exponentially large, concentration is super-exponentially tight. For bounded functionals (rho <= rho_max < infinity on finite state spaces), a simpler bound suffices: by the Markov chain Hoeffding inequality or by the exponential law of exit times (BEGK Thm 1.4), the exit time concentrates around its mean, which directly gives concentration of the occupation times.

    State the alternative: BEGK Thm 1.4 shows tau_{exit}/E[tau_{exit}] -> Exp(1), which already gives concentration of residence times without needing the full DV machinery. Use this simpler route if it suffices.

    Cite Donsker-Varadhan (1975-1983) for the general LDP. Cite BEGK Thm 1.4 for the simpler exit time concentration.

    **Lemma 7 (Ratio Assembly):** Divide the bound from Lemma 5 by the bound from Lemma 4:
      mu_BB / mu_stable <= (rho_max * K_b * exp((Delta_b - alpha)/epsilon) * (1 + delta_5)) / (c * K_s * exp(Delta_s/epsilon) * (1 - delta_4))
    Simplify:
      mu_BB / mu_stable <= C * exp(-(Delta_s - Delta_b - alpha)/epsilon) * product_of_corrections
    where C = (rho_max * K_b) / (c * K_s) and product_of_corrections = (1 + delta_5)/(1 - delta_4) = 1 + O(max(delta_4, delta_5)).

    Verify: C is O(1) in epsilon (does not grow polynomially in 1/epsilon). All K factors come from BEGK prefactors which are rational functions of chain parameters, not epsilon-dependent.

    CRITICAL: Track every c_i value (the rate in the error term) relative to Delta_s - Delta_b. The final bound is valid as stated only if min_i(c_i) > 0 and the correction product remains 1 + O(exp(-gamma/epsilon)) for some gamma > 0. If any c_i = 0, that error term is O(1) and could overwhelm the main term.

    Use probabilist convention throughout: row vectors, piQ = 0, dp/dt = pQ. All references using physicist convention (column vectors, Qp = 0) must be transposed. Entropy in nats (ln, not log2).

    Do NOT re-derive any of the source theorems (BEGK, FW, DV, QSD). Cite them precisely and state the error form. The contribution is composition, not re-derivation. This is explicitly required by the contract (fp-sketch-only rejection).
