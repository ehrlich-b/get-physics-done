    4. For each pair (a,b) with 0 <= a < b <= 8 (36 pairs):

       - For each c in 0..9: compute bracket = (gab/4) @ T_mats[c] - T_mats[c] @ (gab/4).

    Method:
    1. Call compute_spin9_v0_rep() to get 36 M^{(ab)} matrices.
    2. For a 10x10 matrix M, define the "off-diagonal blocks" as:
       - M[S, I] = M[np.ix_([0,1,2,9],[3,4,5,6,7,8])] (spacetime-to-internal block, 4x6)
       - M[I, S] = M[np.ix_([3,4,5,6,7,8],[0,1,2,9])] (internal-to-spacetime block, 6x4)
       A generator preserves the 4+6 split iff BOTH off-diagonal blocks are zero.

    6. Verify stabilizer closure: all brackets [L_i, L_j] in span{L_k} with residual < 1e-12.
    7. Compute Killing form: K_{ij} = Tr(ad(L_i) @ ad(L_j)) where ad(L_i) is the adjoint action matrix.
    8. Compute center: find generators commuting with all others (nullspace of ad).
    9. Compute Killing form eigenvalues and signature to identify the real Lie algebra type.
