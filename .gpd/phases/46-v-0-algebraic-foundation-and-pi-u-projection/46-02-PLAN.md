       Both jordan products use the INTRINSIC h_2(O) product (jordan_product_h2o from Plan 01).

    2. **Compute Delta on all 55 V_0 basis pairs**: For the 10 basis elements from V0_basis_elements(), compute Delta(B_i, B_j) for all i <= j. Store as a structured result.

    3. **Verify Delta = 0 on h_2(C_u) restriction**: The h_2(C_u) basis is:
       - B_0 = H3O(beta=1, gamma=0) [i.e., V_0 basis element b[0]+b[1] = E_{22}]
       - B_1 = H3O(beta=0, gamma=1) [i.e., V_0 basis element b[0]-b[1] = E_{33}]
       - B_2 = H3O(x1=Octonion.basis(0)) [x1 = 1, real off-diagonal]
       - B_3 = H3O(x1=Octonion.basis(7)) [x1 = e_7 = u, imaginary off-diagonal in C_u]

       For all 10 pairs (i<=j) of these 4 basis elements, Delta MUST be zero (< 1e-14).
       Reason: C_u is associative, so jordan_product_h2o commutes with pi_u on h_2(C_u).

    4. **Verify Delta != 0 generically**: Take V_0 basis elements with nonzero W-components (i.e., b[k] for k=2..8 which have x1 = e_0, e_1, ..., e_6 -- wait, b[2] has x1=e_0 which is real, b[3] has x1=e_1 which is in W, ..., b[9] has x1=e_7 which is in C_u).

       Specifically: b[3] through b[8] have x1 = e_1, ..., e_6, which are all in W = Im(O) \ span{e_7}.
       Delta should be nonzero for pairs involving these basis elements.
       If Delta = 0 everywhere, STOP -- this contradicts octonion non-associativity and indicates a bug.

    5. **Characterize Delta structure**: Identify the pattern:
       - Which pairs (i,j) give Delta = 0? Expected: pairs where both x1 components are in C_u.
       - Which pairs give Delta != 0? Expected: pairs where at least one x1 has W-components.
       - What is the magnitude and direction of Delta for nonzero cases?
       - Does Delta have a simple closed-form expression in terms of the W-components?

       The source of Delta is: for a, b in O with W-components, proj_u(a * b) != proj_u(a) * proj_u(b) because the W x W cross-terms in the Fano multiplication table can produce C_u-components. Specifically, for w_1, w_2 in W: w_1 * w_2 has a component in C_u (from the Fano plane structure), but proj_u(w_1) * proj_u(w_2) = 0 * 0 = 0.

    Reference: CONTEXT.md stop condition: "If Delta != 0 on h_2(C_u) restriction, projection formula is wrong."
    Reference: CONTEXT.md stop condition: "If Delta = 0 on all of h_2(O), computation is wrong."
